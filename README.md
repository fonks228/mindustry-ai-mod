# AI Mindustry Mod

**Актуально для Mindustry v8 Build 157.4**

### Как использовать:
1. Нажми клавишу **P** в игре
2. Выбери режим ИИ

### Режимы:
- None — обычное поведение
- Basic — стандартный ИИ
- Aggressive — агрессивная атака
- Defensive — защита базы
- Formation — формации
- Python — самообучаемый режим (в разработке)
